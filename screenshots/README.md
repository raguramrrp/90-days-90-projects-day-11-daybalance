## How to Capture Real Screenshots

1. Launch DayBalance:
   ```cmd
   run.bat
   ```
2. Navigate to `http://localhost:8501`.
3. Open each section using the sidebar navigation.
4. Use Windows Snipping Tool (`Win + Shift + S`) to capture the respective view.
5. Save the captured images into this directory (`screenshots/`) using the filenames listed in the table above.
